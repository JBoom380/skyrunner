# NEON RAIN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A vertical-phone endless chase game: a police hover cruiser racing through five neo-noir megacity districts, 3D pixel-art with a film palette, thumb joystick controls, John's two Suno tracks as the score.

**Architecture:** Same method as Bum Rush: a core (`src/game.js`, done) owns renderer, low-res palette pass, camera, loop, state and scoring; seven modules on `window.NR` talk through `NR.core` and the `NR.bus` event bus; `src/build.py` inlines all scripts into `index.html`. The world is a treadmill (the player stays at z = 0; modules move objects by `core.scroll`).

**Tech Stack:** three.js r186 (bundled classic script), vanilla JS, WebAudio + HTMLAudio, Playwright (Python) for tests.

**Spec:** `src/SPEC.md` (build contract, the source of truth for every interface below). Approved visuals: `mockups/neon_rain_contact_sheet.png`, `mockups/neon_rain_car_sheet.png`, `mockups/neon_rain_title_drafts.png` (draft A, no subtitle).

## Global Constraints
- Original names only: never "Blade Runner", "Deckard", "spinner", "Tyrell", "replicant", "Voight-Kampff", real brands or logos.
- Portrait 9:16, phone-first; 60 fps target on a mid phone; max ~150 draw calls.
- Palette: the 18 colours in `NR.PALETTE`; UI colours amber #e8c890/#d9a050, teal-grey #8fb0b4, dull red #c9584a; no hot pink, no pure cyan.
- Music: RAINY SAX on title/menus/gameplay without restart, then OLD SCHOOL TEST 1, then alternate.
- Title: draft A (detective in the alley, cigarette, smoke), logo "NEON RAIN" with no subtitle.
- No commits or pushes without John's explicit word.
